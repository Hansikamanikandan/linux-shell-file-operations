# 📖 Overview

This experiment demonstrates the power of **Bash shell scripting** by automating common Linux administration tasks using **command-line arguments**, **conditional statements**, **file handling**, and **standard Unix utilities**. These scripts showcase practical solutions for user verification, file management, searching, counting, and maintaining data efficiently.

---

# 🎯 Objectives

- Learn to use command-line arguments in Bash scripts.
- Perform file management operations through shell scripting.
- Verify logged-in users using Linux commands.
- Search, count, and manipulate files.
- Read from and write to text files.
- Develop automation skills for Linux system administration.

# ⚙️ Linux Commands Used

| Command | Purpose |
|---------|---------|
| `who` | Displays currently logged-in users |
| `grep` | Searches for matching text or patterns |
| `cp` | Copies files |
| `ls` | Lists files in a directory |
| `wc -l` | Counts the number of lines/files |
| `touch` | Creates a new file if it does not exist |
| `echo` | Displays output or appends text to files |
